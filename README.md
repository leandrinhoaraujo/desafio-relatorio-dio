# Relatório Financeiro — Power BI

Projeto desenvolvido no Power BI como parte de um desafio de modelagem e análise de dados do bootcamp. O relatório utiliza a base financeira disponibilizada e apresenta informações sobre vendas, custos, lucro, produtos e períodos.

## O que foi desenvolvido

- Indicadores de descontos, vendas, custos e unidades vendidas;
- Gráficos de vendas por mês, produto e data;
- Filtro por ano;
- Navegação entre as páginas do relatório.

## Observação

Por falta de tempo, o projeto não foi concluído por completo. A página **Página 1** ficou sem conteúdo analítico, e alguns ajustes de navegação e acabamento visual previstos no desafio não foram implementados.

## Como visualizar

Abra o arquivo `.pbix` no Power BI Desktop. Use os botões de navegação e o filtro de ano para explorar o relatório.
